# Вариант 03. Мониторинг системных журналов

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** FileSystemWatcher, события, потокобезопасность, Channel, IDisposable

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Читать журнал и выделять INFO, WARNING и ERROR.
2. Подписаться на изменения файла через FileSystemWatcher.
3. Безопасно передавать события наблюдателя в обработчик.
4. Считать количество сообщений каждого уровня потокобезопасно.
5. Обрабатывать новые записи через фиксированных worker-ов.
6. Корректно завершать наблюдатель и освобождать ресурсы.
7. Вынести обработку записей в отдельную DLL.

## Дополнительные задания
8. Добавить bounded Channel между наблюдателем и обработчиками.
9. Сохранять счётчики в реестре Windows.
10. Экспортировать статистику в JSON.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
